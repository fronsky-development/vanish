# Security Policy

## Supported Versions

Only the latest released version of Vanish receives security updates. Please make
sure you are running the most recent release before reporting an issue.

| Version | Supported          |
| ------- | ------------------ |
| 3.1.x   | :white_check_mark: |
| < 3.1   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability, report it privately using one of the
following channels:

- **Email:** support@fronsky.nl
- **GitHub:** open a private [security advisory](https://github.com/fronsky-development/vanish/security/advisories/new)

Please include as much of the following as possible:

- A description of the vulnerability and its potential impact.
- The plugin version (`/vanish info`), Minecraft version, and server software.
- Step-by-step instructions to reproduce the issue.
- Any proof-of-concept code, logs, or screenshots.
- Whether the issue is already known or publicly disclosed elsewhere.

## What to Expect

- We will acknowledge your report within **72 hours**.
- We will investigate and keep you informed of the progress.
- Once fixed, we will release a patched version and, with your permission,
  credit you in the release notes.

## Responsible Disclosure

Please give us a reasonable amount of time to address the issue before any public
disclosure. We are committed to working with you to resolve reported
vulnerabilities quickly and responsibly.

Thank you for helping keep Vanish and its users safe.
